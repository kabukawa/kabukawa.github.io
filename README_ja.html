職務概要

金融情報システムの開発に約20年携わったあと、クラウド上の研究環境と、スタートアップの社内ITを担当してきました。顧客企業に常駐し、開発に加えて、チームの課題、ITガバナンス、情報セキュリティまで扱っています。

中心は、UNIX系（Solaris、CentOS、Red Hat Linux）と Windows の開発、チューニング、障害対応です。AWS と Azure での基盤の運用と改善、金融工学の研究に使う環境の整備、データの収集と前処理も行いました。自動車会社のテレメトリー基盤では、SI のプロジェクトマネージャとして他のベンダと調整し、予定どおりサービスを開始しています。

現職では、インフラと社内ITをまとめて見ています。引き継ぎの資料がない状態から構成を文書に残し、フルリモートでも情報を共有できる状態にすることを大事にしています。

職務経歴

エメラダ株式会社

マネージャー　2021年6月 – 現在

企業向けの資金繰り管理サービス Emerada CashManager の基盤を構築し、保守と運用のリーダーを務めています。信用金庫向けポータルでは、資金繰り管理機能のインフラ設計、構築、運用を担当しています。社内のネットワーク、PC、SaaS の企画から導入、保守、運用までと、情報セキュリティの計画、ポリシー、運用、社員への周知も担当しています。

入社時点ではエンジニアがおらず、引き継ぎ資料もありませんでした。インフラ構成を文書にし、構成図とシーケンス図を含む 200 以上の文書を残して、1名だった体制を 3名に広げました。運用の自動化と手順の簡素化を進め、モブプログラミングと勉強会で、メンバーが自分で課題を扱えるようにしています。インフラの条件と機能の要件をセットで見ることで、急な依頼を減らし、計画して対応できるようにしました。

システム開発部　システムエンジニア　2019年4月 – 2021年5月

インバウンド向け飲食店情報サイトの開発と運用のリーダーを務めました。自動車会社のテレメトリー基盤では、システムの開発と CI/CD の構築、運用を担当し、SI のプロジェクトマネージャとして顧客との窓口になりました。経験の浅いメンバーを一年かけて支え、サービス開始後の運用のとりまとめを、SI 側が担えるところまで戻しました。

株式会社ヴァリューシステム

東京支店　アクティングマネージャ　2012年8月 – 2018年9月

複数拠点にいる自社の開発メンバーの管理とサポートを行いました。SI の下で、金融工学の研究に使うクラウド環境と、システムの開発チームを率いました。当時、金融の現場では AWS の採用例が少なかった中で、短期間のアプリケーション開発を期限内に終えています。その後、ニュースのテキストや株価を扱う研究環境を、顧客担当者と一緒に AWS 上へ整備しました。毎週、概念、利用しているサービス、コスト、AWS CLI を扱う勉強会を開き、顧客企業の社員も含めて、クラウドの依頼に応えられるようにしました。

別の案件では、高速道路の情報提供システムをモバイル対応にするチームのリーダーでした。期間は短く、リリースの1週間前に IE6 対応が追加されましたが、期日までに出しています。

株式会社システナ

開発メンバー、チームリーダー　1992年4月 – 2011年7月

信託銀行の年金運用支援システムを、改修を含めて4年担当しました。銀行の統合に伴うシステム統合では、担当アプリケーションの開発規模が150人月を超えています。損害保険会社の統合では、担当アプリケーションが100人月を超えています。メーカーと SI の開発手法（SDEM）に沿った開発も行いました。

銀行統合の2つのフェーズのうち1つでは、メーカーの予定工数より少ない工数で、品質の高いシステムを作ったとして表彰を受けました。顧客担当者からの相談、ミドルウェアの助言、技術的な支援を担っていました。信託銀行の開発が終わったあとも、名指しで仕事を依頼されています。メーカーの SE からは、Linux 向けミドルウェアの技術支援も依頼されました。
